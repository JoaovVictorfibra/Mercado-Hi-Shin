## Descrição do projeto 🔍
Mercado Hi-shin é um sistema de loja conveniência com dois níveis de acesso: **gerente** e **atendente**.   

- **Gerente** tem acesso completo ao sistema,  
- **Atendente** pode acessar apenas a tela de vendas.   
O sistema possui seis telas:  
- Tela de login  
- Tela principal  
- Cadastro de funcionários  
- Cadastro de produtos  
- Vendas  
- Registro de vendas    
  

Todas as telas estão conectadas ao banco de dados, para cadastrar produtos, usuários e vendas, astelas de vendas e registro buscam produtos cadastrados e vendas registradas forma de pagamento data e hora da compra.  

---




## Objetivo do Software 🎯
Desenvolver um sistema funcional e educativo para gestão de uma loja de conveniência, permitindo o controle de cadastros, vendas e usuários com diferentes níveis de acesso.

---
## Funcionalidade do Sistema ✅
- Login com controle de acesso (gerente ou atendente)
- Cadastro de funcionários (acesso do gerente)
- Cadastro de produtos (acesso do gerente)
- Realização de vendas (acesso do gerente e atendente)
- Registro e consulta de venda realizadas
- Interface grãfica com navegação entre telas
- Conexão com bando de dados para inserção e recuperação de dados
